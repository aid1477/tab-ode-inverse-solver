This project is meant to inverse solve for the parameters given an ODE and its boundary conditions.
It features a custom gradient descent solver, with a custom differentiator, minimizer, and line search algorithm.
It will return the constants for your ODE to fit your given a peak point and other input conditions!

Currently, I am working to improve the solver so it can find lines of solutions given an ODE field. The work for this is largely in TAB_ODE_solver_and_ic_5DEF_LINE.py. Stay tuned!
